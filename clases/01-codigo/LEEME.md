# Clase 1 · Anatomía de una página web — código paso a paso

Cada archivo es la página **completa** en ese momento de la clase. Ábrelos en orden (doble clic o arrástralos al navegador) y compara con el anterior: lo que cambió está entre las marcas `▼▼▼ NUEVO ▼▼▼` y `▲▲▲ fin de lo nuevo ▲▲▲`.

| Archivo | Qué se agrega |
|---|---|
| 01-esqueleto.html | El esqueleto vacío |
| 02-colores-y-tipografia.html | Colores y tipografía (variables CSS) |
| 03-navbar.html | Navbar: HTML + la barra |
| 04-navbar-logo-links-bolsa.html | Navbar: logo, links y bolsa a la derecha |
| 05-hero.html | Hero: la portada |
| 06-hero-boton.html | Hero: el botón reutilizable |
| 07-sidebar-estructura.html | Sidebar y productos: solo la estructura (se ve fea a propósito) |
| 08-sidebar-columnas.html | Sidebar: las dos columnas con grid |
| 09-productos-tarjetas.html | Productos: tarjetas en 3 columnas |
| 10-modal-html.html | Modal: el HTML (existe y estorba) |
| 11-modal-oculto.html | Modal: la capa que cubre todo, oculta (el botón aún no abre) |
| 12-modal-funciona.html | Modal: la cajita y el JavaScript (¡abre y cierra!) |
| 13-footer-FINAL.html | Footer: la página completa |

## Cómo ver los cambios
- **En el navegador:** abre el archivo N y luego el N+1; el cambio salta a la vista.
- **En VS Code:** selecciona dos archivos → clic derecho → *Compare Selected*. Te marca línea por línea qué se añadió.

## Para tu proyecto
Parte del `01-esqueleto.html`, cópialo como `mi-landing.html` y ve agregando lo mismo con tus textos y tus fotos. Los archivos son el ejemplo (Maison Luz); tu landing es tuya.
